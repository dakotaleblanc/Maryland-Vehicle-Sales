Are used vehicles becoming more popular than new ones? When is the best month to sell a vehicle? Have vehicle sales changed over time?

These are the kinds of questions businesses have that can be answered by a visualization. In this project, I took a messy data set about vehicle sales in Maryland over a 20+ year time period and used it to create a dashboard in Power Bi that business owners can use. 

Using Power Query, I cleaned the messy data set, renamed columns, and added a new column for total vehicle sales. 
I then used Power Bi to create models for my dashboard to answer some questions about Vehicle Sales.

Using the visualization, we can see the answers the beginning questions were:
1) Yes, since 2015, used vehicles have been sold more than new vehicles in Maryland.
2) June and September are historically the best selling months in Maryland on average.
3) Yes, in 2008 and 2020 there was a crash drop in sales.

Data set I used can be found at: https://lnkd.in/eViTWnaJ
